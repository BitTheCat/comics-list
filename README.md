# comics-list

Tauri + Vue + TypeScript scaffold for a comics collection manager.

This repository contains an initial scaffold (minimal) with:
- Rust (src-tauri) initializing a SQLite DB and exposing tauri commands
- Vue 3 + Vite frontend that calls tauri commands

Work in progress — run `npm install` then `npm run tauri:dev` to start (requires Rust + Tauri prerequisites).
